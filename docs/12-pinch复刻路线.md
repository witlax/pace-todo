# pinch 复刻路线（1.1.0 → 1.2.x）

> 编制：2026-11-23 · 依据：pinch v2.8.0 源码（159k 行，240 文件）与 5 张实机截图
> 原则：**界面与操作逻辑 1:1，底层用本地数据；不复刻思源文档体系与网络同步。**

---

## 1. 为什么不是「连代码一起复刻」

| | pinch | 本项目 |
| --- | --- | --- |
| 代码量 | 159,265 行（114,781 Vue + 44,484 TS） | 20.5k 行 Dart |
| 最重组件 | `TaskManager.vue` 13,441 行 | 全项目 20.5k |
| 数据来源 | 思源笔记块（文档 / 块引用 / 属性） | 本地 SQLite |
| 分发形态 | 思源插件（浏览器内核 + 插件 API） | 独立 Android / Windows 应用 |

它的体量里有三块是「思源专属」或与本地优先冲突的：

1. 文档体系：`DocumentGroupManagerPanel`、`SourceFilterSelect`、`TaskTitleRich`（块引用徽章）
2. 网络：`calendarDavClient` / `calendarSync` / `calendarCloudSync`（CalDAV、S3、WebDAV、OAuth）
3. 游戏化商城：`RewardPanel`（金币消费、奖励兑换）

因此复刻范围定为：**看得见的界面与摸得到的操作**，数据全部落在本地表里。

## 2. 已确认的四个决策（2026-11-23）

| # | 问题 | 结论 |
| --- | --- | --- |
| 1 | 首页顶部 Lv / 碎片 / 金币 | **真做，本地规则**：1 碎片 = 任务 1 个 / 达标打卡 1 天 / 专注 10 分钟；40 碎片 1 级；10 碎片 1 币；不做商店消耗 |
| 2 | 日历同步 | **放弃 CalDAV**（2026-11-23 修订）：CalDAV 要常驻网络与账号密码存储，收益低。改为「导出 `.ics`」，后期用 **WebDAV / S3 做备份同步**（评估见 `docs/13`） |
| 3 | 任务管理区 | **外观 + 常用操作复刻**：行样式、分组、排序、搜索、重要性筛选、长按菜单；不做多条件保存视图 |
| 4 | 起手页 | **首页 + 导航**（骨架先立，后面几页挂上去） |

## 4. 1.1.0 的落地细节

### 4.1 导航

```
首页   视图   专注   日志   目标   设置
```

- `TabId` 从 5 项可配置改为 6 项固定；`nav.middle` 设置项废弃（旧值读取时映射 `today→home`、`calendar→view`，`habits/memos` 直接忽略）。
- 长按每个 tab 仍有次级入口：首页→搜索/已完成/回收站；视图→今日概览/备忘录/习惯管理；专注→今日概览/习惯统计；日志→心情打卡/备忘录；目标→目标管理/已完成目标；设置→备份/外观/日志。

### 4.2 首页结构

```
[等级徽章] Lv.N  x/40 碎片  [progress]            [🪙 N]
<            2026年11月            >
[一 23][二 24][三 25][四 26][五 27][六 28][日 29]
⌄ 习惯打卡                              ⋮  📈  ＋
   （习惯卡片：名称 / 周期 / 连续天数 / 圆圈，7 天小格可长按补卡）
⌄ 任务管理                              ↻  ＋
[全部 ▾]  今天                  🔍 ⚙ ⋮
   （任务行：○ 标题 … M-d ⋯）
```

- 日期格决定任务区口径：显示「该日之前到期 + 无日期 + 该日完成」的任务，无日期的不隐藏。
- 习惯区固定今天（打卡只能打今天，补卡在卡片 7 天格上长按）。
- 成长值点一下弹说明：今天任务/习惯/专注各贡献多少碎片。

### 4.3 打卡动作单一来源

`habit_actions.dart` 提供 `habitQuickCheckIn` / `habitOpenJournal` / `showHabitBar`，
首页与习惯页共用。**1.0.0 的心得 bug 就是两份实现分叉导致的**，这次收敛成一份。

### 4.4 日志页（基础版）

心情五档统计 + 当天心情、周日期条、专注/任务/习惯三张卡、当天时间线、每日总结。
总结暂存 `SharedPreferences`（`log.note.yyyy-MM-dd`），第 3 轮进表时做一次迁移。

## 5. 与 pinch 的已知差异（不打算抹平）

| 差异 | 原因 |
| --- | --- |
| 没有思源文档/块引用任务来源 | 我们不是思源插件，任务来自本地库 |
| 没有金币商店与奖励兑换 | 与「零负担、本地优先」冲突，金币只作记录 |
| 没有 CalDAV / 云发布 / OAuth | 不申请网络权限；以导出 `.ics` 替代 |
| 多一个「四象限」视图 | 本地特色，已有用户在用，保留在视图页第五段 |
| 多一个「备忘录」模块 | pinch 用思源笔记承担，我们内置轻量版 |
| 没有甘特图 / 表格视图 | 手机不可用，归入不做清单 |

## 6. 下一轮（1.2.0 专注页）要动的数据

现状：`FocusState{plannedSec, remainingSec, elapsedSec, mode, running, finished}`，
只有倒计时/正计时，没有短休与组数。

需要补：

| 字段 | 说明 |
| --- | --- |
| `cycles` | 本轮总共几组（1–8） |
| `cycleIndex` | 当前第几组 |
| `breakSec` | 短休时长（1/3/5/10/15 分钟） |
| `phase` | focus / break / done 三态 |
| `linkType` | habit / task / tag（计时关联胶囊） |

`FocusSessions` 表已有 `mode`（0 番茄 1 正计时 2 休息），休息段直接落 `mode=2`，
不新建表。参数默认值存 `SharedPreferences`（`focus.plannedMin` / `focus.breakMin` / `focus.cycles`）。

## 7. 第 2 轮落地（1.3.0）

与 pinch 的差异是刻意保留的：

| 项 | pinch | 我们 | 原因 |
| --- | --- | --- | --- |
| 参数卡位置 | 圆环下方常驻 | 收进右上角齿轮 | 手机上圆环 + 卡 + 按钮一屏放不下，主按钮必须常驻可见 |
| 关联任务 | 顶部三个胶囊（习惯/任务/标签） | 顶部一个下拉 | 标签维度暂不做，两个入口反而更绕 |
| 白噪音 | 6 场景 + 音量 | 4 场景 + 音量 | 用户明确表示不扩展场景 |
| 迷你瓶 | 系统悬浮窗 | 应用内右下角胶囊 | 悬浮窗要 overlay 权限且长期驻留耗电 |

### 7.1 专注循环

```
专注 25 分 ──► 短休 5 分 ──► 专注 25 分 ──► … ──► 结算
     每段结束落一条 session（mode=0），短休不落库
```

- `FocusState` 新增 `cycles / cycleIndex / breakSec / phase / totalActualSec`
- 休息中按钮变「跳过休息」；「结束」在休息段直接收尾
- 结算与结束通知都用 `totalActualSec`（跨组累计），不再用「计划 × 组数」

### 7.2 剩下的差距

- 白噪音仍是运行时合成，音色不如真实素材，但零素材零版权
- 计时关联只支持任务，没有「标签」维度
- 没有 pinch 的「开启迷你瓶」开关（应用内胶囊默认常开，专注结束自动消失）
