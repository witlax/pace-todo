# 数据模型 v1（schemaVersion = 1）

> 用途：M0 建表与迁移的唯一依据。任何字段增删改，必须同时更新本文、写迁移、记 DEVLOG；破坏兼容需 ADR。
> 关联：ADR-0002（Drift）、ADR-0007（SQLite）、ADR-0011（备忘录）、ADR-0012（重要性）。

---

## 1. 通用约定

| 约定 | 说明 |
| --- | --- |
| 主键 | `TEXT` 存 UUIDv7（时间有序），客户端生成，不用自增 |
| 时间 | `INTEGER` 存 UTC 毫秒；另有 `tz` 记录创建时区，用于"归属日"计算 |
| 软删除 | 所有业务表带 `deleted_at`（`NULL` 表示未删），查询默认过滤 |
| 版本 | 所有业务表带 `rev`（整数，写入时 +1）与 `updated_at`、`device_id`，为同步预留 |
| 布尔 | `INTEGER` 0/1 |
| 枚举 | `INTEGER`，取值在代码中用 Dart enum 映射，**不用字符串** |
| 文本 | `TEXT`，Markdown 原样存储 |

## 2. 表定义

### 2.1 任务域

```sql
CREATE TABLE folders (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, sort_order INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE lists (
  id TEXT PRIMARY KEY, folder_id TEXT, name TEXT NOT NULL,
  color INTEGER, icon TEXT, sort_order REAL DEFAULT 0,
  is_inbox INTEGER DEFAULT 0,        -- 收件箱，全局唯一，不可删
  default_view TEXT,                  -- 覆盖默认视图（ADR-0010）
  archived INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  list_id TEXT NOT NULL,              -- 逻辑外键
  parent_id TEXT,                     -- 单层子任务：父任务不可再有父
  title TEXT NOT NULL,
  notes TEXT,                         -- Markdown 备注（与备忘录无关）
  status INTEGER DEFAULT 0,           -- 0 待办 1 完成 2 取消
  importance INTEGER DEFAULT 0,       -- 0 无 1 低 2 中 3 高（ADR-0012）
  start_at INTEGER, due_at INTEGER, all_day INTEGER DEFAULT 0,
  estimate_min INTEGER, spent_min INTEGER DEFAULT 0,
  repeat_rule TEXT,                   -- RRULE 字符串
  repeat_mode INTEGER DEFAULT 0,      -- 0 固定日程 1 完成后顺延
  repeat_from_id TEXT,                -- 重复实例的母任务
  remind_json TEXT,                   -- [{"offset":-600},{"repeat":true}]
  completed_at INTEGER, pinned INTEGER DEFAULT 0,
  sort_order REAL DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE tags (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, color INTEGER,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE task_tags (
  task_id TEXT NOT NULL, tag_id TEXT NOT NULL, PRIMARY KEY (task_id, tag_id)
);
```

### 2.2 习惯与专注

```sql
CREATE TABLE habits (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, icon TEXT, color INTEGER,
  freq_type INTEGER NOT NULL,         -- 0 每日 1 每周N次 2 指定星期 3 每月
  freq_config TEXT,                   -- {"weekDays":[1,3,5]} 或 {"times":3}
  target_count INTEGER DEFAULT 1, unit TEXT,
  remind_at TEXT,                     -- "HH:mm" 或 NULL
  link_focus INTEGER DEFAULT 0,       -- 与专注联动
  archived INTEGER DEFAULT 0, sort_order REAL DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE habit_logs (
  id TEXT PRIMARY KEY, habit_id TEXT NOT NULL,
  date TEXT NOT NULL,                 -- 归属日 YYYY-MM-DD（本地日）
  count INTEGER DEFAULT 1, note TEXT,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE focus_sessions (
  id TEXT PRIMARY KEY, task_id TEXT,
  mode INTEGER NOT NULL,              -- 0 番茄 1 正计时 2 休息
  started_at INTEGER NOT NULL, ended_at INTEGER,
  planned_sec INTEGER, actual_sec INTEGER,
  note TEXT,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);
```

### 2.3 备忘录域（ADR-0011）

```sql
CREATE TABLE notes (
  id TEXT PRIMARY KEY, title TEXT, body_md TEXT,
  color INTEGER, importance INTEGER DEFAULT 0,   -- 0 无 1 低 2 中 3 高（与任务同义）
  pinned INTEGER DEFAULT 0, archived INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  deleted_at INTEGER, rev INTEGER DEFAULT 1, device_id TEXT
);

CREATE TABLE note_assets (
  id TEXT PRIMARY KEY, note_id TEXT NOT NULL,
  type INTEGER NOT NULL,              -- 0 图片 1 文件
  local_path TEXT NOT NULL,           -- assets/notes/<note_id>/<uuid>.webp
  mime TEXT, width INTEGER, height INTEGER, size INTEGER,
  created_at INTEGER NOT NULL, deleted_at INTEGER
);

CREATE TABLE task_note_links (
  task_id TEXT NOT NULL, note_id TEXT NOT NULL,
  mode INTEGER NOT NULL,              -- 0 引用 1 快照
  sort_order INTEGER DEFAULT 0, created_at INTEGER NOT NULL,
  PRIMARY KEY (task_id, note_id)
);
```

### 2.4 系统

```sql
CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);

CREATE TABLE sync_meta (
  key TEXT PRIMARY KEY, value TEXT    -- device_id / last_sync_at / cursor
);
```

## 3. 索引与全文检索

```sql
CREATE INDEX idx_task_list_status_due ON tasks(list_id, status, due_at);
CREATE INDEX idx_task_parent ON tasks(parent_id);
CREATE INDEX idx_task_due ON tasks(due_at) WHERE deleted_at IS NULL;
CREATE INDEX idx_task_created ON tasks(created_at) WHERE deleted_at IS NULL;  -- 专注中新任务查询
CREATE INDEX idx_focus_started ON focus_sessions(started_at);
CREATE UNIQUE INDEX idx_habit_log ON habit_logs(habit_id, date) WHERE deleted_at IS NULL;
CREATE INDEX idx_note_updated ON notes(updated_at);
CREATE INDEX idx_note_sort ON notes(pinned DESC, importance DESC, created_at DESC);
CREATE INDEX idx_link_note ON task_note_links(note_id);

CREATE VIRTUAL TABLE tasks_fts USING fts5(title, notes, content='tasks', content_rowid='rowid');
CREATE VIRTUAL TABLE notes_fts USING fts5(title, body_md, content='notes', content_rowid='rowid');
```

> 中文检索：FTS5 默认按 `unicode61` 分词，中文按字切分效果可用；若召回不佳，M1 再评估 `trigram` 分词器（需在迁移中重建索引）。

## 4. 关键语义

| 字段 | 语义 | 易错点 |
| --- | --- | --- |
| `tasks.due_at` | 截止时刻；全天任务取当日 23:59:59.999（本地） | 全天任务不要存 00:00，否则"今天到期"会提前一天失效 |
| `tasks.importance` | 0–3 四档，只有它决定颜色 | 不要用布尔 `urgent`，四象限需要三档区分 |
| `habits.freq_type` + `freq_config` | 频率定义 | 每周 N 次按"自然周"计，跨周清零 |
| `habit_logs.date` | **归属日**，不是时间戳 | 跨时区旅行时以用户当时的本地日为准，不改写历史 |
| `notes.body_md` | Markdown 原文，图片以 `![](asset://<asset_id>)` 引用 | 不要存绝对路径，换设备会失效 |
| `notes.importance` | 0–3，与任务共用四色语义 | 用于排序与色条，不参与四象限 |
| `task_note_links.mode` | 0 引用 / 1 快照 | 快照是复制，不随源变化 |
| `tasks.repeat_mode` | 0 固定 / 1 完成后顺延 | 顺延的下次时间基于 `completed_at`，不是 `due_at` |

## 5. 迁移策略

1. `schemaVersion` 从 1 开始，每次结构变更 +1。
2. 迁移写在 `core/db/migrations.dart`，按 `from → to` 顺序注册，禁止跳版本。
3. 破坏性变更（删字段/改类型）必须：新增列 → 回填 → 保留旧列一个版本 → 再删。
4. 每次迁移必须有测试：从每个历史版本升到最新，校验行数与关键字段。
5. 大表迁移（万级以上）需在事务中分批，避免 ANR。

## 6. 备份格式（backup-v1）

```
backup-v1.zip
├─ manifest.json     { "version": 1, "schemaVersion": 1, "exportedAt": ..., "deviceId": ... }
├─ data.json         { "lists": [...], "tasks": [...], "notes": [...], ... }
└─ assets/notes/<note_id>/<uuid>.webp
```

- 只导出未软删数据；`deleted_at` 不导出。
- 恢复时校验 `schemaVersion`：低于当前则先迁移，高于当前则拒绝并提示升级。
- 缺失附件不阻断恢复，列出清单让用户知情。
