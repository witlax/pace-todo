安装包：`dist/tasks-0.3.0-release.apk`（63.6 MB，三 ABI，debug 签名）
版本：`0.3.0+3`，schema v2（自动从 v1 迁移，旧数据保留）

---

## 一、这一版按你的反馈改了什么

| # | 你提的问题 | 现在的行为 |
| --- | --- | --- |
| 1 | 添加任务能设置的内容太少，必须二次编辑 | 快速添加右上角 **高级模式** → 完整新建页：清单、日期、提醒、重复、重要性、备注一次配齐 |
| 2 | 时间要精确到分钟，并且能加提醒 | 日期改成「选日 + 选时分」；新增独立提醒：准时 / 提前 10 分钟 / 提前 1 小时 / 自定义 / 不提醒 |
| 3 | 备忘录添加后点不进去 | 卡片整块可点，进入编辑页（标题 / 正文 / 置顶 / 重要性 / 删除） |
| 4 | 长按删除改为右滑选择删除或归档 | **右滑**弹出动作面板：归档 / 删除，各自标了后果；长按删除已移除 |
| 5 | 已完成任务不要消失，要变灰、能看完成时间、能写总结 | 今日页「今日完成」分组：变灰 + 删除线 + 完成于 HH:mm；详情页顶部可写完成总结，可一键撤销完成 |
| 6 | 专注时间无法自定义 | 增加「自定义」，范围 5–180 分钟 |
| 7 | 对齐 Pinch 所有功能 | 见 `docs/08-Pinch功能对齐.md`：逐屏拆解 + A/B/C/D 标注 + 5 项明确不做 |

## 二、建议测试路径（约 8 分钟）

1. **右滑动作**
   在今日页任一任务上**向右滑** → 出现「归档 / 删除」面板 → 选归档。
   预期：任务从列表消失；设置 → 归档 里能找到它，可「取消归档」。

2. **新建成完整任务**
   点 + → 输入标题 → 点右上「高级模式」→ 设「日期」为今天 18:47 → 「提醒」选提前 10 分钟 → 保存。
   预期：回到列表能看到 `今天 18:47`；通知应在 18:37 到达（需允许通知）。

3. **完成态与总结**
   点任务左侧圆圈完成。
   预期：任务**不消失**，落到「今日完成」分组，变灰、带删除线、显示「完成于 HH:mm」；
   点进去可写「完成总结」，返回后列表显示摘要；再点圆圈可撤销完成。

4. **备忘录**
   底部（若已开启）或 设置 → 备忘录 → 新建一条 → 返回 → **点卡片**。
   预期：进入编辑页，可改标题正文、置顶、设重要性。

5. **专注自定义**
   今日页右上计时器 → 「自定义」→ 输入 12 → 确定。
   预期：圆环显示 12:00，开始后正常倒数；可点全屏图标进入全屏专注。

## 三、数据迁移说明

- 首次启动会把数据库从 v1 升到 v2，新增三列（完成总结、提醒时间、归档时间），**旧任务全部保留**；
- 已实测：升级后原有任务与已完成记录都在，日志里有 `数据库迁移完成：v1 → v2`。
