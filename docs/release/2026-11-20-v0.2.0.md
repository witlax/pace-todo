## 二、建议的测试路径（约 10 分钟）

1. **重复任务**
   新建一条任务 → 打开详情 → 点「不重复」选「每天」→ 返回 → 点圆圈完成。
   预期：任务消失，列表出现同一标题、到期为明天的任务。

2. **子任务**
   任意任务详情 → 在「添加子任务」输入后回车，加两条 → 勾完两条。
   预期：父任务自动移入已完成；今日清单里子任务从不单独出现。

3. **标签与清单**
   设置 → 清单 → 新建「项目 A」→ 长按拖动排序 → 归档，里面的任务应回到收件箱。
   任务详情 → 标签 → 新建标签并勾选。

4. **搜索**
   今日页顶部搜索栏 → 输入任意关键词。
   预期：键盘自动弹出，结果按「任务 / 备忘录」分组；返回后列表位置不丢。

5. **全屏专注**
   今日页右上角计时器 → 右上角全屏图标 → 点「开始」。
   预期：状态栏与按钮淡出；横过来变成左右两栏，倒计时不重置；
   此时回桌面新建一条任务，全屏页底部出现「专注中新加入 1 个任务」。

6. **备份**
   设置 → 备份与恢复 → 导出到文件，记下路径。
   故意删几条任务 → 从最近的备份文件恢复 → 确认数据回来。

## 三、已知限制（不要按 bug 报）

| 项 | 说明 |
| --- | --- |
| 前台服务未接 | 专注在切后台/锁屏后可能被系统挂起，这是下一步 |
| 小组件 / 分享接收 / 托盘 | 未实现（M6） |
| 备忘录图片 | 未实现，当前只支持文本与链接文本 |
| 搜索实现 | 用 `LIKE` 而非 FTS5，几千条以内无感；后续换 FTS5 只改查询层 |
| 日历拖拽改期 | 未实现，当前通过详情改日期 |
| 提醒可靠性 | 需真机验证；模拟器不休眠，测不出来 |

## 四、验证记录

- `flutter analyze`：0 issue
- `flutter test`：**19/19 通过**（新增 7 项：重复规则与生成、子任务级联、归档清单、标签、备份往返、子任务不入清单）
- Android release 构建：82.1 s，62.6 MB
- 模拟器（API 35 / 360 dp）实测：
  - 新建任务 → 详情 → 设「每天」→ 完成 → 列表出现明天的同名任务（截图核对 `之后 · 明天`）
  - 详情页完整显示 清单/日期/重要性/重复/置顶 五个 chip、子任务、标签、关联备忘录
  - 设置页五段（我的内容 / 导航栏 / 提醒 / 外观 / 数据 / 开发者 / 关于）均正常渲染
- 修复的两个实际缺陷：
  1. rrule 只接受 UTC，本地时间直接传入会被断言吞掉 → 重复任务根本不会生成；改成内部 UTC 后通过
  2. 重复选择弹层最后一项被系统导航栏遮挡 → 改为可滚动并允许完整高度
