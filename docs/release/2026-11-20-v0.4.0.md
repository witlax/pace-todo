## 一、按你上一条反馈的对应关系

| # | 反馈 | 处理 |
| --- | --- | --- |
| 1 | 右滑改左滑 | 任务行滑动方向改为**左滑**（endToStart），动作面板从底部弹出 |
| 2 | 归档后「撤销」提示一直不消失 | 提示条显式 **4 秒**自动消失 |
| 3 | 新建页与编辑能力对齐 | 新建页可预选**标签**与**关联备忘录**，保存时一并写入；置顶在详情里设 |
| 4 | 备忘录太简陋，要图片、链接、Markdown | 全面升级，见下 |

备忘录升级参考了你截图的 Monica 应用形态，但有两个刻意差异：

- **不做富文本，做 Markdown 源文件**。富文本会把内容锁进私有格式，导出、全文搜索、跨端都会变麻烦；Markdown 是纯文本，备份里就是原文。
- **图片复制进应用目录**而不是引用相册路径。相册的临时文件随时可能被系统清掉，复制一份才真正离线可用。

## 二、备忘录现在的能力

| 能力 | 说明 |
| --- | --- |
| 编辑 / 预览 | 顶栏一键切换，预览用 `MarkdownBody` 渲染 |
| 工具条 | 标题、加粗、斜体、待办、列表、引用、代码、链接、插图——只做「插入标记」 |
| 图片附件 | 相册选图 → 复制到 `note-assets/` → 缩略图九宫格；点开大图可缩放，长按移除 |
| 标签 | 逗号分隔轻量文本，列表卡片直接显示 |
| 反向引用 | 编辑页底部显示「被 N 个任务引用」 |
| 置顶 / 重要性 | 与任务共用同一套四色语义 |
| 删除 | 右上菜单，软删 |

链接的说明：预览里链接可点，但**只显示地址不跳转**——V1 没接 `url_launcher`，与其做出一个「点了没反应」的假链接，不如明确告诉你地址是什么。接外链跳转是下一步的事。

## 三、建议测试路径（约 6 分钟）

1. **左滑**
   今日页任一任务**向左滑** → 动作面板弹出（归档 / 删除）→ 取消（点面板外）。
   注意：往右滑没有反应，这是设计。

2. **提示条**
   归档一条 → 底部「已归档：xxx · 撤销」→ **4 秒后自动消失**，不用手动关。

3. **新建页预选**
   + → 高级模式 → 「标签」选一个、「关联备忘录」勾一条 → 保存 → 打开该任务详情。
   预期：详情里标签已勾选、关联备忘录已列出。

4. **备忘录**
   新建备忘录 → 保存后直接进编辑页 → 正文输入：
   ```
   # 结论
   **加粗** 和 `代码`
   - 第一条
   - 第二条
   ```
   → 切「预览」看渲染 → 工具条试「加粗」「链接」→ 「添加图片」从相册选一张 → 缩略图出现 → 点开大图 → 长按缩略图移除。

5. **反向引用**
   任务详情 → 关联备忘录 → 选刚建的备忘录 → 回到备忘录编辑页。
   预期：底部出现「被 1 个任务引用」。
