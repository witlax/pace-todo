## 2. 这一版能做什么

| 模块 | 能力 |
| --- | --- |
| 任务 | 新建（重要性 + 今天/明天/无日期）、编辑标题与备注、改重要性、改日期、在清单间移动、就地新建清单 |

| 视图 | 清单 / 四象限切换（重要性 × 截止 3 天） |

| 日历 | 月视图、按天查看、点某天直接新建 |
| 专注 | 15/25/45 分钟、关联任务、环形进度、结束后写回任务耗时与今日统计 |
| 习惯 | 新建、一键打卡、连续天数、近 7 天格子、长按补卡 |
| 备忘录 | 文本备忘录列表与新建 |

| 设置 | 导航栏、提醒权限入口、回收站、外观、版本 |

## 3. 建议的测试路径（约 10 分钟）

1. 新建 3 条任务：一条「今天 18:00 + 高」，一条「明天 + 中」，一条「无日期 + 低」。
2. 看列表分组与色条是否正确，切到四象限看分桶。
3. 点圆圈完成一条，立即点「撤销」。
4. 点整行进详情，改标题、加备注，返回看列表是否同步。
5. 长按一条删除，去 设置 → 回收站 恢复。
6. 日历里点明天，加一条任务，回到今天看是否出现在「之后」。
7. 专注页选一条任务，跑 1 分钟结束，看今日分钟数是否增加、任务详情是否累计耗时。
8. 习惯页新建一个，打卡，再长按昨天补卡，看连续天数。
9. 设置里关掉「习惯」Tab，看底部是否立刻变化；重启 App 看是否记住。
10. 给一条任务设 2 分钟后的时间，锁屏等通知（关键验证项）。
