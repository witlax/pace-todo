## 二、几个位置决策

- **今日概况入口放在今日页右上角**，而不是设置里。理由：它回答的是「今天怎么样」，
  属于当下上下文；放进设置就变成需要专门去找的报表。设置里的入口只会削弱它。
- **视图页默认工作台**。打开应用先看今天的产出与待办，而不是一个空日历。
- **看板用横向滚动而不是四列压缩**。360 dp 下四列各 85 dp 会挤成纸条，
  宁可一屏看两列半，滑动切换。

## 三、建议测试路径（约 8 分钟）

1. 底部「视图」→ 工作台：三指标、7 天柱状、打卡热力、专注分布；右上 tune 切到看板。
2. 看板切「今天 / 本周 / 本月」，确认列内任务随范围变化。
3. 习惯 → + → 填名称、选「按周」勾几天、设提醒时间 → 创建。
4. 点习惯圆圈：应弹出确认层（不是直接完成）→ 写一句心得 → 完成打卡；
   再点一次可撤销。
5. 点习惯名称进详情：月进度环、打卡日志、总进度；点某天可补卡。
6. 习惯页右上 insights：切本周/本月/本年看各习惯完成率。
7. 今日页右上柱状图 → 今日概览。
8. 日历月视图看日期格「待办·完成」；点「这天」看当天回顾；切周视图看时间轴。
9. 任务行右侧箭头展开子任务。
10. 备忘录 → 添加附件 → 选一个 PDF/图片。
