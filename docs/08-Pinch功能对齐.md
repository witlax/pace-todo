# Pinch 功能对照（0.11.0 实况版）

> 参照：`pinch-main`（片趣打卡 v2.8.0，75 个 Vue 组件 / 60 个 composable）
> 本文已按 2026-11-22 的 0.11.0 重写；早期 0.3.0 版本的 A/B/C/D 判断保留在 git 历史。
> 级别：**A** 已对齐 ｜ **B** 简化实现 ｜ **C** 形态不同 ｜ **D** 不做 ｜ **G** 缺口（应补）

---

## 1. 结论

- **任务域**：模型与交互基本对齐（A 占多数），差距集中在「视图形态」与「通知动作」。
- **习惯域**：**界面像了，模型没到**——周期只存不判、次数只显示不判定，这是当前最大缺口。
- **专注域**：倒计时闭环完整（含前台服务），缺正计时、补时、习惯绑定。
- **聚合层**：目标、心情、统计配置均缺；奖励按定位不做。

一句话：**外观复刻约 80%，模型复刻约 60%**。下一阶段的重点不是加界面，是把三个模型补正。

## 4. 三个必须补正的模型

### 4.1 频率模型（0.12 P0）

现状：`freqConfig = weekly:1,3,5` 只是字符串；`habit_detail_page` 的「计划打卡」用整月天数；
`calcStreak` 按自然日连续。于是「每周一三五」的习惯，周二会被算成断签。

要求：抽 `features/habits/habit_schedule.dart`，提供 `scheduledOn / plannedBetween / streak`，
所有页面（列表、详情、统计、热力）只准调用这一处，并配 ≥12 条单测。

### 4.2 完成模型（0.12）

`habit_logs.count`（默认 1）+ 达到 `targetCount` 才算当日完成；卡片显示 `3/8 杯`；
撤销按次递减，归零才删记录。

### 4.3 目标模型（0.13）

`goals` + `goal_links`，四种进度：任务 / 习惯 / 专注 / 手动。
目标不做子目标树，保持一层。

## 5. 明确不做（更新）

1. **积分 / 等级 / 碎片 / 商店**：与「不打扰、不评判」冲突。
2. **表格视图、甘特图**：手机无可用形态。
3. **文档任务收集、块徽章**：思源特有，离开思源无意义。
4. **困难程度**：只在积分体系有意义。
5. **底部字符统计**：无决策价值。
6. **CalDAV 同步**：本地优先，同步是独立课题。

> 注：早期版本这里写过「工作台不做（与今日页重叠）」。0.10.0 已删掉今日页的统计入口，
> 统计只在视图 → 工作台，职责不再重叠，故该项移出不做清单。
